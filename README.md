# TurfNation

TurfNation is a full-stack turf booking platform that enables users to discover, book, and manage sports turf reservations online. The application provides a seamless booking experience with a modern user interface and a robust backend powered by Spring Boot.

## Features

- User registration and authentication
- Browse available turfs and time slots
- Book turf slots online
- View and manage bookings
- RESTful API integration
- Responsive user interface
- Secure backend architecture

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- Maven

### Database
- MySQL

## Installation and Setup

### Clone the Repository

```bash
git clone <repository-url>
cd TurfNation
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

## Prerequisites

- Java 17 or later
- Node.js and npm
